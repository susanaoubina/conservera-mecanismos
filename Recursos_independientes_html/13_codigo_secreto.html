Código secreto: la clave de salida

A = 1 · B = 2 · … · Z = 26
Cifrar: sumar K
Descifrar: restar K
¿De qué va esto?
Para salir de la conservera hace falta la clave del candado de la puerta corredera. Carme la escondió con un código numérico: cada letra se convirtió en un número y después le sumó un número secreto K. Los seis números que habéis conseguido en las fichas forman ese código. Para descifrarlo, primero hay que averiguar K… y Carme lo dejó escrito como una operación en la mesa del fondo.
  • Resolver una operación con paréntesis respetando el orden de las operaciones.
  • Entender cómo funciona un código numérico: A = 1, B = 2… y un desplazamiento K.
  • Restar K a cada número y usar la tabla para conseguir la clave del candado.
¿Cómo funciona el código de Carme?

Letras → números

Cada letra se cambia por su posición en el alfabeto: A = 1, B = 2, C = 3… Z = 26 (alfabeto de 26 letras, sin Ñ).

Cifrar

A cada número se le suma K. Con K = 4, la C (3) se convierte en 3 + 4 = 7.

Descifrar

Se hace al revés: a cada número del código se le resta K y se busca la letra en la tabla. Con K = 4, el 7 → 7 − 4 = 3 → C.
